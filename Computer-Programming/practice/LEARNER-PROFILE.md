# Learner Profile (Computer Programming · C#)

สรุปจากแบบสอบถาม 50 ข้อ ใช้เป็นแนวทางออกแบบเว็บฝึก ([index.html](index.html)) ทุกบท

## วิธีเรียนรู้
- **ดูให้เห็นภาพก่อน → ค่อยลงมือ** (ชอบคลิปคนสอนจริงพร้อมตัวอย่าง) — ไม่ชอบอ่านยาว ๆ
- เข้าใจดีสุดด้วย **analogy** (ชอบมาก) และ **animation โค้ดรันทีละบรรทัด** / diagram
- คำอธิบาย: **สั้น ตรงประเด็น** หรือสั้นก่อนแล้วกดดูละเอียดได้
- ภาษา: ไทยปนศัพท์อังกฤษ (อยากสลับได้)
- อ่านโค้ดคนอื่น: ต้องไล่ทีละบรรทัด และงงบ่อย
- จำได้ดีเมื่อ **เขียนโค้ดเอง + ทำ quiz**
- เรียน **ตามสิ่งที่จะสอบ**
- สมาธิ 30–60 นาที

## พื้นฐาน (1–5)
| เรื่อง | คะแนน |
|---|---|
| Variable / if-else / Loop | 3 |
| Nested loop | 1 |
| Methods | 2 (เข้าใจหลักการ แต่เขียน/ใช้ไม่เป็น) |
| Array 1D / 2D | 1 |
| Class & Object | 1 |
| String methods | 1 |
| Debug | 2 |
| Trace โค้ดในหัว | 1 (ไม่รู้จักคำว่า trace) |

งงที่สุด: **Class/Object > Array > Method > Nested loop**

## จุดติด
- Error ที่เจอบ่อย: **syntax error**
- ติดตั้งแต่อ่านโจทย์ → คิด logic → แปลงเป็นโค้ด
- อ่าน error message เข้าใจบางที
- ติดแล้วถาม AI, ไม่ใช้เว็บเพราะไม่เข้าใจการสอนแบบอ่าน
- อยากให้ช่วยตอนติดตามลำดับ: **ชี้บรรทัดที่ผิด → ถามกลับให้คิด → บอกคำตอบ**
- ไม่เคยใช้ pseudocode / flowchart

## แรงจูงใจ
- เรียนเพื่อทุกอย่าง (เกรด + เก่งจริง + โปรเจกต์) เป้าหมาย **เกรด A** อยากเป็นที่ 1
- Gamification: เฉย ๆ
- เลิกกลางคันเพราะ **น่าเบื่อ / เหนื่อย** · ตอบผิดแล้วหงุดหงิดนิดหน่อย
- หัวข้อโจทย์ที่ชอบ: **เงิน, อนาคต, AI**
- ตัวเอง 3 คำ: ขยัน · เข้าใจง่าย · เบื่อง่าย
- ติวเตอร์ที่อยากได้: **ตรง ๆ ดุนิด ๆ + ตลก เป็นกันเอง**

## นิสัยการเรียน
- เรียนช่วงค่ำ–ดึก, ทวนทุกวันหรือ 2–3 ครั้ง/สัปดาห์
- ใช้โน้ตบุ๊ก/แท็บเล็ต ไม่ชอบทำบนมือถือ · **dark mode**
- IDE: VS Code, Visual Studio · อยากได้ spaced repetition
