## 4. แนวทางเทคนิค (เบื้องต้น)
- เป็นเว็บ static (HTML + CSS + JavaScript) ไม่มี backend จึงรันบน GitHub Pages ได้เลย
- เก็บคำศัพท์ในไฟล์ `data/*.json` เพิ่มคำใหม่ได้โดยไม่ต้องแก้โค้ด
- ตัวอย่างโครงข้อมูล:
  ```json
  {
    "word": "achieve",
    "pos": "verb",
    "meaning_th": "บรรลุ, ทำสำเร็จ",
    "example": "She worked hard to achieve her goals.",
    "topic": "Education"
  }
  ```
- ต้องตัดสินใจ: ใช้ HTML ล้วน หรือใช้ framework (React/Vite)
  - ข้อเสนอ: เริ่มด้วย HTML ล้วนเพราะง่ายและ deploy ง่าย

## 6. Deploy บน GitHub Pages
- Settings → Pages → Source: เลือก branch และโฟลเดอร์
- หรือใช้ GitHub Actions deploy เฉพาะโฟลเดอร์นี้
- ยังต้องคุย: แยกเป็นรีโปใหม่ไหม (ได้ URL สั้นกว่า) หรือเก็บไว้ในรีโปนี้

## 9. ช่วงท้ายคาบ: คำถามสุ่ม 5 ข้อ (สรุปจากการระดมไอเดีย)
| หัวข้อ | สิ่งที่ตกลงกันแล้ว |
|---|---|
| ตำแหน่งในคาบ | 7:00–9:00 (แทน Picture quiz เดิม) ประมาณ 2 นาที |
| การสุ่ม | **สุ่มแบบกำหนดสัดส่วน**: 🔴 ยาก 2 · 🟡 กลาง 2 · 🟢 ง่าย 1 ไม่มีคำซ้ำ ไม่สุ่มคำว่า *obscene* |
| รูปแบบคำถาม | **ภาพ + เนื้อเพลงใต้ภาพ** (เว้นช่องตรงคำศัพท์) → ทายคำ |
| วิธีเล่น | **ขึ้นจอหน้าห้อง ทั้งห้องตอบพร้อมกัน** กดปุ่ม "สุ่ม 5 ข้อ" บนเว็บ |
| ภาษา | คำถามและเนื้อเพลงเป็นภาษาอังกฤษ มีซับไทย |

| เนื้อเพลงใต้ภาพ | คำ🔴ยากใช้บรรทัดจากเพลงจริง ส่วนคำ🟡กลางกับ🟢ง่ายใช้ **ท่อนสั้นที่แต่งเพิ่ม** (ใช้เฉพาะในควิซและบนเว็บ) อยู่ในฟิลด์ `lyric` ของ `data/vocab.json` |
| การตอบ | **มีตัวเลือก A–D** ทั้งห้องตะโกนตอบตัวอักษร ตัวเลือกหลอกเป็นชนิดคำเดียวกับคำตอบ |

**ยังรอ:** โทนและไอเดียการตกแต่งเว็บ (ทีมจะมาบอก)
