## 4. แนวทางเทคนิค (เบื้องต้น)
- เป็นเว็บ static (HTML + CSS + JavaScript) ไม่มี backend จึงรันบน GitHub Pages ได้เลย
- เก็บคำศัพท์ในไฟล์ `data/*.json` เพิ่มคำใหม่ได้โดยไม่ต้องแก้โค้ด
- ตัวอย่างโครงข้อมูล:
  ```json
  {
    "word": "achieve",
    "pos": "verb",
    "meaning_th": "บรรลุ, ทำสำเร็จ",
    "example": "She worked hard to achieve her goals.",
    "topic": "Education"
  }
  ```
- ต้องตัดสินใจ: ใช้ HTML ล้วน หรือใช้ framework (React/Vite)
  - ข้อเสนอ: เริ่มด้วย HTML ล้วนเพราะง่ายและ deploy ง่าย

## 9. ช่วงท้ายคาบ: คำถามสุ่ม 5 ข้อ (สรุปจากการระดมไอเดีย)
| หัวข้อ | สิ่งที่ตกลงกันแล้ว |
|---|---|
| ตำแหน่งในคาบ | 7:00–9:00 (แทน Picture quiz เดิม) ประมาณ 2 นาที |
| การสุ่ม | **สุ่มเฉพาะคำที่สอนที่ฐาน**: 🔴 คำยาก 3 ข้อ (จากการ์ดภาพและเพลง) + กลุ่มคำ 2 ข้อ (enthusiasm, enthusiastic, assign, assignment, instruct, instructions) ตัวเลือกหลอกก็มาจากคำที่สอนเช่นกัน ไม่มีคำซ้ำ และไม่สุ่มคำว่า *obscene* (เดิมเป็น ยาก 2 · กลาง 2 · ง่าย 1 จากทุกคำ แต่จะมีคำที่ไม่ได้สอน) |
| รูปแบบคำถาม | **ภาพ + เนื้อเพลงใต้ภาพ** (เว้นช่องตรงคำศัพท์) → ทายคำ |
| วิธีเล่น | **ขึ้นจอหน้าห้อง ทั้งห้องตอบพร้อมกัน** กดปุ่ม "สุ่ม 5 ข้อ" บนเว็บ |
| ภาษา | คำถามและเนื้อเพลงเป็นภาษาอังกฤษ มีซับไทย |

| เนื้อเพลงใต้ภาพ | คำ🔴ยากใช้บรรทัดจากเพลงจริง ส่วนคำ🟡กลางกับ🟢ง่ายใช้ **ท่อนสั้นที่แต่งเพิ่ม** (ใช้เฉพาะในควิซและบนเว็บ) อยู่ในฟิลด์ `lyric` ของ `data/vocab.js` |
| การตอบ | **มีตัวเลือก A–D** ทั้งห้องตะโกนตอบตัวอักษร ตัวเลือกหลอกเป็นชนิดคำเดียวกับคำตอบ |

## 10. รูปแบบการสอนจริง: วนฐานเป็นกลุ่ม
- ผู้เรียนเป็นกลุ่ม **แยกกลุ่มคนไทยกับกลุ่มต่างชาติ** แล้ววนมาที่ฐานของเรา
- ทั้งหมดมี 6–7 กลุ่ม **เริ่มวางแผนที่ 5 กลุ่มก่อน** แล้วค่อยเพิ่ม
- แต่ละกลุ่มอยู่ที่ฐาน **10 นาที** (สอน 9.5 นาที + เปลี่ยนกลุ่ม 0.5 นาที) กลุ่มละ **5–6 คน**
- 5 กลุ่มรวมประมาณ 50 นาที (7 กลุ่มประมาณ 70 นาที)
- อุปกรณ์: **โน้ตบุ๊ก + จอ monitor** ใช้แบบจอขยาย (extend) ให้โน้ตบุ๊กเป็นจอผู้สอน (ปุ่มควบคุม, โน้ต, ตัวจับเวลา) ส่วน monitor เป็นจอผู้เรียน
- ควรเตรียม **ลำโพงพกพา** เพราะลำโพงโน้ตบุ๊กเบา และต้องคุมเสียงไม่ให้รบกวนฐานอื่น

**ผลกระทบต่อแผนเดิม**
| เรื่อง | เดิม | ใหม่ |
|---|---|---|
| เพลง | เวอร์ชันผสม | กลุ่มไทยใช้ **🇹🇭 เวอร์ชันไทย** กลุ่มต่างชาติใช้ **🌏 English Version** (เวอร์ชันผสมเก็บไว้ใช้ตอนรวมทุกกลุ่ม) |
| ท่อน Bridge แบ่งฝั่ง | ใช้ | ตัดออก เพราะในกลุ่มมีภาษาเดียว |
| สไลด์/เว็บ | 2 ภาษาในหน้าเดียว | **ปุ่มสลับ TH / EN** กดครั้งเดียวเปลี่ยนทั้งชุดเมื่อกลุ่มใหม่เข้ามา |
| คำถามสุ่ม 5 ข้อ | สุ่ม 1 รอบ | **สุ่มใหม่ทุกกลุ่ม** กลุ่มหลังจะได้ไม่รู้คำตอบจากกลุ่มก่อน |
