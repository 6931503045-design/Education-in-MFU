| ต้องมี | รายการคำศัพท์แยกตามหัวข้อหรือบท | คำ, ความหมายไทย, ชนิดคำ, ประโยคตัวอย่าง |
| ต้องมี | Flashcard พลิกดูความหมาย | |

| ควรมี | ฟังเสียงอ่าน | ใช้ Web Speech API ของเบราว์เซอร์ ไม่ต้องมีไฟล์เสียง |

## 4. แนวทางเทคนิค (เบื้องต้น)
- เป็นเว็บ static (HTML + CSS + JavaScript) ไม่มี backend จึงรันบน GitHub Pages ได้เลย
- เก็บคำศัพท์ในไฟล์ `data/*.json` เพิ่มคำใหม่ได้โดยไม่ต้องแก้โค้ด
- ตัวอย่างโครงข้อมูล:
  ```json
  {
    "word": "achieve",
    "pos": "verb",
    "meaning_th": "บรรลุ, ทำสำเร็จ",
    "example": "She worked hard to achieve her goals.",
    "topic": "Education"
  }
  ```
- ต้องตัดสินใจ: ใช้ HTML ล้วน หรือใช้ framework (React/Vite)
  - ข้อเสนอ: เริ่มด้วย HTML ล้วนเพราะง่ายและ deploy ง่าย

## 5. โครงไฟล์ที่คาดไว้ (ตอนลงมือทำเว็บ)
```
vocab-exam-web/
├── index.html        หน้าแรก (เลือกหัวข้อ)
├── flashcards.html
├── quiz.html
├── css/style.css
├── js/app.js
└── data/vocab.json
```

## 6. Deploy บน GitHub Pages
- Settings → Pages → Source: เลือก branch และโฟลเดอร์
- หรือใช้ GitHub Actions deploy เฉพาะโฟลเดอร์นี้
- ยังต้องคุย: แยกเป็นรีโปใหม่ไหม (ได้ URL สั้นกว่า) หรือเก็บไว้ในรีโปนี้

## 7. คำถามที่ต้องตอบก่อนเริ่มทำ
1. คำศัพท์มาจากไหน (เนื้อหาในวิชา, รายการ TOEIC, Oxford 3000)
2. ต้องมีกี่คำ กี่หัวข้อ
3. ทำคนเดียวหรือทำเป็นกลุ่ม (แบ่งงานยังไง)
4. ส่งงานเมื่อไหร่ อาจารย์ต้องการอะไรบ้าง
5. ชื่อเว็บ / ธีม / สี
