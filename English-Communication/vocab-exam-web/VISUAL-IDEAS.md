# ไอเดียภาพประกอบการสอน

## หลักการ: ทำภาพชุดเดียว ใช้ได้ทั้ง 2 เวอร์ชัน
ภาพสื่อความหมายได้โดยไม่ต้องใช้ภาษา จึงใช้ภาพชุดเดียวกันทั้งสองกลุ่ม เปลี่ยนแค่ข้อความบนสไลด์

| ส่วนบนสไลด์ | 🇹🇭 คนไทย | 🌏 ต่างชาติ |
|---|---|---|
| ภาพ | ภาพเดียวกัน | ภาพเดียวกัน |
| คำศัพท์ | ✔ | ✔ |
| ข้อความใต้คำ | ความหมายไทย + คำอ่าน | นิยามภาษาอังกฤษสั้น ๆ + ประโยคตัวอย่าง |

## เทคนิคให้ภาพช่วยจำได้จริง
1. **มีตัวละครหลัก 1 ตัว** เช่น นักศึกษา มฟล. ให้ปรากฏในทุกภาพ ภาพทั้งชุดจะเหมือนเล่าเรื่องเดียวกัน ทำให้จำง่ายกว่าภาพที่ไม่เกี่ยวกัน
2. **ภาพเกินจริงหรือตลก** จำได้ดีกว่าภาพธรรมดา (เช่น หูขยายใหญ่สำหรับ *attentively*)
3. **ภาพก่อน/หลัง** เหมาะกับคำกริยาที่เปลี่ยนสภาพ (alleviate, enhance, minimise)
4. **ใช้สีตามระดับ** 🔴 ยาก / 🟡 กลาง / 🟢 ง่าย ให้กรอบสไลด์เป็นสีเดียวกับระดับ
5. **ภาพเดียวกับในเพลง** ตอนเปิด lyric video ให้ภาพของคำนั้นขึ้นพร้อมเนื้อร้อง
6. **ภาพตอน Quiz** แสดงแค่ภาพแล้วให้ทายคำ ใช้ทบทวนได้ดีมาก

## หาภาพจากไหน
- **AI สร้างภาพ** เช่น Canva, Bing Image Creator หรือ ChatGPT ตัวอย่าง prompt:
  `Cute flat cartoon illustration, a Thai university student [ไอเดียภาพ], simple white background, bright colors`
- **ภาพฟรี** จาก Unsplash, Pexels หรือ Freepik
- **ไอคอน** จาก Flaticon (ใช้กับคำง่าย ๆ อย่าง fetch, thirsty)
- ⚠️ *obscene* ห้ามใช้ภาพจริง ให้ใช้ป้าย 18+ หรือแถบเซ็นเซอร์แทน

## 🔴 ยาก (เพลง): 18 คำ (ทำภาพละเอียด 1 คำต่อ 1 สไลด์)

| คำ | ความหมายไทย | ไอเดียภาพ | ตัวช่วยจำ |
|---|---|---|---|
| **alleviate** | บรรเทา, ทำให้เบาลง | ภาพก่อน/หลัง: คนปวดหัวหน้าเหยเก กินยาแล้วยิ้ม | ก้อนหินหนักบนหลัง ถูกยกออก |
| **attentively** | อย่างตั้งใจ, อย่างใส่ใจ | นักศึกษาฟังเลกเชอร์ ตาโต หูขยายใหญ่ | attention! = ตั้งใจ! |
| **constructive** | สร้างสรรค์ (ติเพื่อก่อ) | ครูวงงานด้วยปากกาแดง ในมือถือค้อนช่างก่อสร้าง | construct = ก่อสร้าง → ติเพื่อก่อ |
| **diligently** | อย่างขยันขันแข็ง | มดแบกอาหารเป็นแถว / นักศึกษาทำการบ้านตอนดึก | มดคือสัญลักษณ์ความขยัน |
| **enhance** | ทำให้ดีขึ้น, เพิ่มคุณภาพ | รูปก่อน/หลังใส่ฟิลเตอร์ หรือปุ่ม HD | en + hance → ยกระดับ (higher) |
| **enthusiastically** | อย่างกระตือรือร้น | เชียร์ลีดเดอร์กระโดดโห่ร้อง ยกมือสุด | เทียบกับ enthusiasm / enthusiastic ในชุดเดียวกัน |
| **extracurricular** | นอกหลักสูตร (กิจกรรม) | นักศึกษาเล่นดนตรี/กีฬา นอกห้องเรียน | extra = นอกเหนือ, curriculum = หลักสูตร |
| **pandemic** | โรคระบาดใหญ่ (ทั่วโลก) | ลูกโลกใส่หน้ากากอนามัย | pan = ทั้งหมด (ทั้งโลก) |
| **proofread** | ตรวจทาน, พิสูจน์อักษร | แว่นขยายส่องกระดาษ มีปากกาแดงวงคำผิด | proof (พิสูจน์) + read (อ่าน) |
| **intruder** | ผู้บุกรุก | โจรใส่หน้ากากปีนหน้าต่างตอนกลางคืน | in (เข้า) + rude (หยาบคาย) = เข้ามาแบบไม่ขออนุญาต |
| **assortment** | ของหลายอย่างรวมกัน, ของคละ | กล่องช็อกโกแลตรวมรส / ถุงขนมคละ | กล่องเดียวมีหลาย sort (หลายแบบ) |
| **etiquette** | มารยาท, ธรรมเนียมที่สุภาพ | โต๊ะอาหารฝรั่งจัดมีดส้อม คู่กับภาพไหว้แบบไทย | ออกเสียงเหมือน 'เอ-ทิ-เค็ท' ติดป้าย (ticket) ว่าสุภาพ |
| **minimise** | ลดให้น้อยที่สุด | ปุ่มย่อหน้าต่าง [–] บนจอคอมพิวเตอร์ | ปุ่ม minimise บนคอม = ย่อให้เล็กสุด |
| **misperception** | การเข้าใจผิด, การรับรู้ผิด | ภาพลวงตาเป็ด/กระต่าย หรือคนเห็นเชือกเป็นงู | mis (ผิด) + perception (การรับรู้) |
| **obscene** | ลามก, อนาจาร, หยาบคาย | ป้าย 18+ หรือแถบเซ็นเซอร์ดำ (ห้ามใช้ภาพจริง) | มีแถบเซ็นเซอร์ = obscene |
| **reciprocal** | ซึ่งกันและกัน, ตอบแทนกัน | สองคนเกาหลังให้กัน / ลูกศรวนไป-กลับ | ให้ไป ↔ ได้คืน |
| **remarkably** | อย่างน่าทึ่ง, อย่างโดดเด่น | คนอ้าปากค้าง 'WOW!' ข้างปากกาไฮไลต์ | re-mark = ควรค่าแก่การทำเครื่องหมาย |
| **severance** | การตัดขาด (ความสัมพันธ์) | กรรไกรตัดเชือกที่ผูกคนสองคนไว้ | sever ≈ ตัดให้ขาด |
