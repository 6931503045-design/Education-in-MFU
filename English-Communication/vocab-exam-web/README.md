# Sing the Words! (เว็บต้นแบบ)

เว็บสอนคำศัพท์ 1006134 English for Communication 1 (บทที่ 1–3) ผ่านภาพและเพลง

| หน้า | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าแรก |
| `presenter.html` | **Presenter mode** สำหรับผู้สอนที่ฐาน (เปิดบนโน้ตบุ๊ก) |
| `stage.html` | จอผู้เรียน (เปิดจากปุ่มในหน้า Presenter แล้วลากไปที่ monitor) |
| `study.html` | ผู้เรียนฝึกเองบนมือถือ: Flashcards + ควิซสุ่ม 5 ข้อ |

## วิธีใช้ที่ฐาน (โน้ตบุ๊ก + monitor)
1. ต่อ monitor แล้วตั้งค่าจอเป็น **Extend** (ขยายจอ ไม่ใช่ mirror)
2. เปิด `presenter.html` บนโน้ตบุ๊ก แล้วกด **🖥️ เปิดจอผู้เรียน** หน้าต่างใหม่จะเด้งขึ้นมา ลากไปที่ monitor แล้ว **ดับเบิลคลิกให้เต็มจอ**
3. กลุ่มใหม่เข้ามา: กด **➕ กลุ่มใหม่** แล้วเลือก **ไทย / English** ระบบจะสุ่มควิซชุดใหม่และรีเซ็ตเวลาให้
4. กด **→** หรือ **Space** เพื่อไปต่อ เวลา 10 นาทีจะเริ่มนับเมื่อกดครั้งแรก
5. ควิซสุ่ม 5 ข้อถามเฉพาะคำที่สอนที่ฐาน (คำยาก 3 + กลุ่มคำ 2) ช่วงควิซ: ให้กลุ่มตอบ แล้วกด **R** เฉลย จากนั้นกด **C** (ถูก) หรือ **X** (ผิด) ส่วน **H** ใช้แสดงคำใบ้
6. ช่วงเพลง: กด **P** เล่นหรือหยุดเพลง แล้วกด → เลื่อนเนื้อร้องตามจังหวะ

คะแนนของทุกกลุ่มบันทึกไว้ในตารางด้านขวา ข้อมูลอยู่ในเบราว์เซอร์ของโน้ตบุ๊กเครื่องนั้น

**ไม่มีอินเทอร์เน็ตก็ใช้ได้:** ดับเบิลคลิกเปิด `presenter.html` จากไฟล์ในเครื่องได้เลย ฟอนต์จะเปลี่ยนเป็นฟอนต์ของระบบแทน

## แก้เนื้อหา
| อยากแก้ | ไฟล์ |
|---|---|
| **โทนสี / ฟอนต์ / ความโค้งมน** | `css/theme.css` (ไฟล์เดียว) |
| คำศัพท์ ความหมาย เนื้อเพลงสำหรับควิซ | `data/vocab.js` |
| เนื้อเพลงที่ขึ้นจอ, กลุ่มคำ | `data/songs.js` |
| ภาพ | ใส่ไฟล์ใน `images/` (ดู `images/README.md`) |
| ไฟล์เพลง | ใส่ไฟล์ใน `audio/` |
