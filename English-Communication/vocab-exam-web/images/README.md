# ภาพประกอบ

ใส่ภาพชื่อ `<คำศัพท์>.png` แล้วเว็บจะใช้ภาพนั้นแทนอีโมจิให้อัตโนมัติ
- ใช้ตัวพิมพ์เล็ก และใช้ `-` แทนช่องว่าง เช่น `minimise.png`, `catch-up.png`, `visual-aids.png`
- ภาพสี่เหลี่ยมจัตุรัสจะดูดีที่สุด (เช่น 800×800)
- `qr.png` คือ QR code ที่ขึ้นในหน้าสรุป
- ไอเดียภาพของแต่ละคำอยู่ใน [../VISUAL-IDEAS.md](../VISUAL-IDEAS.md)
