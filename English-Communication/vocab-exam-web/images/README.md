# ภาพประกอบ

- **คำยาก 18 คำ** (`<คำ>.jpg`): ภาพที่ทีมหามาเอง แปลงเป็น JPG และย่อด้านยาวสุดไม่เกิน 1000 px โดยไม่ครอป ไฟล์ที่ใช้กำหนดไว้ในฟิลด์ `img` ของ `data/vocab.js`
- **คำอื่น** (`<คำ>.png`): มาจาก **[Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji)** (สไตล์ Color) สัญญาอนุญาต **MIT** ข้อความสัญญาอนุญาตอยู่ใน [LICENSE-fluent-emoji.txt](LICENSE-fluent-emoji.txt)

เว็บแสดงภาพแบบเต็มภาพ ไม่ครอป ภาพแนวนอนหรือแนวตั้งจะมีขอบสีพื้นเติมให้เป็นกรอบสี่เหลี่ยม

## เปลี่ยนเป็นภาพของตัวเอง
ใส่ไฟล์ทับชื่อเดิมได้เลย (`<คำศัพท์>.jpg` สำหรับคำยาก และ `<คำศัพท์>.png` สำหรับคำอื่น) ถ้าจะใช้ชื่อหรือนามสกุลอื่น ให้แก้ฟิลด์ `img` ของคำนั้นใน `data/vocab.js`
- ใช้ตัวพิมพ์เล็ก และใช้ `-` แทนช่องว่าง เช่น `minimise.png`, `catch-up.png`, `visual-aids.png`
- ภาพสี่เหลี่ยมจัตุรัสจะดูดีที่สุด (เช่น 800×800)
- `qr.png` คือ QR code ที่ขึ้นในหน้าสรุป
- ไอเดียภาพของแต่ละคำอยู่ใน [../VISUAL-IDEAS.md](../VISUAL-IDEAS.md)

ภาพที่ยังสื่อความหมายได้ไม่ดี: `underneath` (เป็นแค่แมว ไม่เห็นว่าอยู่ "ข้างใต้")
