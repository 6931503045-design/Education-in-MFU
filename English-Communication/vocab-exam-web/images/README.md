# ภาพประกอบ

ภาพคำศัพท์ตอนนี้มาจาก **[Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji)** (สไตล์ Color) ซึ่งใช้สัญญาอนุญาต **MIT** ใช้บนเว็บสาธารณะได้ฟรี ข้อความสัญญาอนุญาตอยู่ใน [LICENSE-fluent-emoji.txt](LICENSE-fluent-emoji.txt)
แต่ละภาพแปลงเป็น PNG ขนาด 800×800 พื้นโปร่งใส คำที่ใช้อีโมจิ 2–3 ตัว (pandemic, misperception, various) นำภาพมาวางรวมกันเป็นภาพเดียว

## เปลี่ยนเป็นภาพของตัวเอง
ใส่ไฟล์ทับชื่อเดิมได้เลย ชื่อไฟล์คือ `<คำศัพท์>.png`
- ใช้ตัวพิมพ์เล็ก และใช้ `-` แทนช่องว่าง เช่น `minimise.png`, `catch-up.png`, `visual-aids.png`
- ภาพสี่เหลี่ยมจัตุรัสจะดูดีที่สุด (เช่น 800×800)
- `qr.png` คือ QR code ที่ขึ้นในหน้าสรุป
- ไอเดียภาพของแต่ละคำอยู่ใน [../VISUAL-IDEAS.md](../VISUAL-IDEAS.md)

ภาพที่ยังสื่อความหมายได้ไม่ดี ควรเปลี่ยนก่อน: `minimise` (เป็นแค่เครื่องหมายลบ) และ `underneath` (เป็นแค่แมว ไม่เห็นว่าอยู่ "ข้างใต้")
